ROBUILDER WEBSITE FILES

index.html = the website
assets/site-config.js = public Roblox Priority experience URL + display price
assets/portfolio.js = the list of portfolio projects
assets/images/profile/ = paste the RoBuilder logo here
assets/images/portfolio/ = paste portfolio images here

Priority is handled by a Roblox Developer Product. The website never trusts a browser payment button; the Roblox server processes the receipt and the Firebase backend marks only the linked submission as IMPORTANT.

Run the site through VS Code Live Server or Firebase Hosting instead of opening index.html with file://.
